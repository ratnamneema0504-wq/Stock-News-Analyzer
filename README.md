Stock News Analyzer
An AI-powered financial news analysis application built with Python and Streamlit. Stock News Analyzer combines retrieval-augmented generation (RAG), semantic search, sentiment analysis, historical market-impact analytics, and machine-learning models to explore a bundled financial-news dataset.
Disclaimer: This project is for educational and analytical purposes only. Its dataset and outputs are not live market data, investment recommendations, or financial advice.

Features
- RAG-powered chat: Ask questions about the available financial-news dataset. Relevant records are retrieved before the local language model generates an answer.
- Semantic search: Sentence Transformers generate text embeddings, while FAISS retrieves relevant news records.
- Sentiment analysis: Explore positive, negative, and neutral news sentiment.
- Interactive dashboard: Review news trends and dataset-level summaries using interactive visualizations.
- Market impact analysis: Examine historical price changes, price direction, top gainers and decliners, and sector-level patterns where the required fields are available.
- Machine-learning models:
  - Decision Tree classification to model historical price direction.
  - K-means clustering to group news articles using text features.
  - Human-readable IF-THEN rules extracted from the trained decision tree.
- Custom CSV upload: Upload a compatible CSV from the sidebar. The uploaded dataset replaces the bundled data for the current app session.
- Evidence guardrail: The chat checks retrieval similarity and declines to generate an answer when the available dataset does not provide sufficient evidence.

Dataset
The default dataset is data/stock_market_news_extended_15000.csv. It contains 15,000 generated sample records covering 30 companies across seven sectors, with dates spanning 2019–2025. The records include fields for company, sector, news source, topic, sentiment, price before and after the news event, percentage change, price direction, impact, volume, and article body.

The project also includes an earlier 5,000-row CSV. The active dataset can be selected with the DATA_FILE setting in .env.

Data note: The extended dataset is generated by tools/generate_extended_dataset.py for project demonstration and analysis. It should not be treated as verified historical exchange data or as a source of real-time market information.
Getting Started
Prerequisites
- Python 3.10 or later recommended
- Git
- Ollama, if you want to use the AI chat feature
1. Clone the repository
git clone https://github.com/ratnamneema0504-wq/Stock-News-Analyzer.git
cd Stock-News-Analyzer
2. Create and activate a virtual environment
Windows PowerShell:
python -m venv .venv
.venv\Scripts\Activate.ps1
If PowerShell blocks activation, you can use Command Prompt instead:
.venv\Scripts\activate.bat
macOS / Linux:
python3 -m venv .venv
source .venv/bin/activate
3. Install dependencies
python -m pip install --upgrade pip
pip install -r requirements.txt
4. Configure the application
Copy the example environment file:

Windows PowerShell:
Copy-Item .env.example .env
macOS / Linux:
cp .env.example .env
The default .env.example settings are:
OLLAMA_MODEL=llama3.2:3b
DATA_FILE=stock_market_news_extended_15000.csv
TOP_K_DEFAULT=8
SIMILARITY_THRESHOLD=0.30
EMBEDDING_MODEL=all-MiniLM-L6-v2
MAX_ARTICLE_CHARS=6000
Adjust these values in .env if required. Do not commit API keys, credentials, or other secrets.
5. Set up Ollama (for AI chat)
Install Ollama, then download the default model:
ollama pull llama3.2:3b
Make sure the Ollama service is running before using the chat feature. The dashboard and dataset-based analysis can be used independently of generated chat responses.
6. Run the development server
streamlit run app.py
Open the local address shown in the terminal, normally:
http://localhost:8501

Using a Custom Dataset
Use the Add your own news CSV uploader in the sidebar. The application validates the uploaded file and uses it for the current session. At minimum, provide the fields required by the uploader's validation (news, company, and date or year); additional analysis features require their corresponding columns. Refer to src/config.py for the bundled dataset's column mapping.

To change the default bundled CSV, set DATA_FILE in .env to its filename inside the data/ directory. If you replace a dataset manually, remove the existing generated FAISS index and metadata so the application can rebuild the index for the new data.
Running Tests
From the project root, with the virtual environment activated:
python -m pytest -q
Limitations
- The application analyzes the bundled or user-uploaded dataset; it does not fetch live financial news, live stock prices, or external company information.
- The extended bundled dataset is generated sample data, not verified historical exchange data.
- Market-impact analysis describes patterns in the available records. It does not establish that a news item caused a price movement.
- Machine-learning outputs are demonstrations based on the supplied dataset and are not forecasts of future market performance.
- AI chat quality depends on the retrieved records and the locally installed Ollama model.
